Pour installer sur Linux, cloner le repository "Invoke-Obfuscation.  
`sudo apt-get instal powershell -y` pour installer powershell.  
`pwsh` pour lancer powershell  
`cd ./Invoke-obfuscation` pour aller dans repo  
`Import-Module ./Invoke-obfuscation.psd1` pour importer module  
`Invoke-obfuscation` pour lancer le script.
