
SimpleHTTPServer (python2)  
http.server (python3)  

- SimpleHTTPServer (python2) : `python -m SimpleHTTPServer 80` : par defaut le serveur est créé sur la machine locale.   

- http.server (python3) : `python3 -m http.server 80`
